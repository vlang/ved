Built for flow

Small editor. Serious machinery.

Ved keeps the surface quiet and the internals fast. Everything below works out of the box, with no plugin setup.

Hardware-accelerated text rendering

Text is drawn through the GPU, so highlighting and scrolling stay responsive on large buffers. Syntax is lexed per line and drawn in colored chunks instead of repainting whole screens.

  • Visible-range rendering: cost tracks your viewport, not file size
  • Syntax definitions loaded from the syntax folder and overridable in your config
  • Light and dark themes, base16-style color configuration

Find anything, instantly

Fuzzy file finder with Ctrl+P. Search inside a file with /, or across the whole workspace with git grep using ?.

Git, in the editor

Commit with Ctrl+C, inspect a diff with Ctrl+-, and jump to definitions without leaving your buffer.

Vim muscle memory

Motions, operators, visual mode, yank and paste, search navigation, and repeat. Workspaces, splits, and a built-in timer round out the package.

Two minutes in

From zero to editing.

Grab a release below, or build from source with V. Open a directory to get a workspace, then use Ctrl+P to jump between files.

Most people never need to touch a config file. If you do, create conf.toml in ~/.ved.

shell
$ git clone https://github.com/vlang/ved
$ cd ved
$ v .
$ ./ved path/to/project
Get started

Download ved

Pick your platform. Each release ships a ready-to-run binary; no V installation required.

Windows ved-windows-x86_64.zip 64-bit · unzip and run ved.exe Debian / Ubuntu ved-x86_64.deb sudo apt install ./ved-x86_64.deb Fedora / RPM ved-x86_64.rpm sudo dnf install ./ved-x86_64.rpm

Prefer to build it yourself? Follow the source build instructions. macOS builds are produced by CI; grab the artifact from the latest workflow run until a signed release is added.
